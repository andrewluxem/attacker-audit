# Security

This repo contains markdown instructions only. There is no code to exploit, but the instructions can still be wrong in ways that matter: a check that tells the agent to do something unsafe, or guidance that would lead someone to a false sense of safety.

If you find one of those, open an issue. If it's sensitive (for example, a way the skill could be made to leak secrets from the audited repo into its report or elsewhere), use GitHub's private vulnerability reporting on this repo instead.

Do not report vulnerabilities in other people's projects here.
